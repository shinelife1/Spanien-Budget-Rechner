# 🇪🇸 Spain Budget Expert 2026

## ⚖️ Lizenz
Dieses Projekt ist unter der **MIT-Lizenz** lizenziert – siehe die [LICENSE](LICENSE) Datei für Details.


Ein leistungsstarkes CLI-Tool (Command Line Interface) zur präzisen Planung der Lebenshaltungskosten in Spanien. 

## 🚀 Highlights & Features
- **Interaktives Dashboard:** Eine saubere, farbkodierte Konsole für den perfekten Überblick.
- **Echtzeit-Synchronisation:** Anzeige der aktuellen Berliner Zeit (Europe/Berlin) für präzise Planung.
- **Daten-Persistenz:** Automatisches Speichern und Laden deiner Daten via `JSON`.
- **Intelligente Visualisierung:** Dynamische Fortschrittsbalken zeigen den Anteil der Kosten am Netto-Gehalt.
- **Robustes Error-Handling:** Abgesichert gegen falsche Nutzereingaben durch `try-except` Blöcke.

## 🛠 Technische Details
- **Sprache:** Python 3.9+
- **Module:** `json`, `datetime`, `zoneinfo`, `requests`
- **Konzept:** Modulare Programmierung mit Funktionen und Dictionary-basierten Datenstrukturen.

## 📥 Installation
1. Repository klonen:
   ```bash
   git clone https://github.com
   ```
2. Abhängigkeiten installieren:
   ```bash
   pip install -r requirements.txt
   ```
3. Programm starten:
   ```bash
   python rechner.py
   ```
